# EXP-013: Underdog de-ranking bonus

**Status:** Ready to run
**Effort:** Small
**Priority:** Medium
**Agent:** awards-builder

---

## Task

Add an underdog boost to the scoring pipeline and measure how many new projects enter the top 30.

## Inputs

- `iterations/project-b/project-summaries.json` — contains `underdog_signal`, `github_stars`, `team_size` fields
- `results.json` — current rankings baseline
- `the-algorithm.ts` — current scoring implementation

## Method

1. Define underdog boost criteria: `underdog_signal = true` AND (`github_stars < 500` OR `team_size = "small"`)
2. Set boost values: +5 for one signal, +10 for both signals simultaneously
3. Apply boost to current v5 heuristic scores (or as a post-processing step on raw results)
4. Re-sort and produce `results-underdog-boost.json`
5. Compare top 30 before and after:
   - Which projects enter the top 30 that weren't there before?
   - Which projects drop out?
   - What is the net rank change for projects with the underdog signal?

## Output

- `experiments/EXP-013/results-underdog-boost.json`
- `experiments/EXP-013/analysis.md` — before/after comparison table, summary of new entrants

## Constraints

- Do NOT modify `results.json` or `the-algorithm.ts` permanently — this is an experiment
- Save results as a separate file with clear naming

## Definition of done

Boosted results produced, before/after comparison analysis written.
