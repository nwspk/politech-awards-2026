# EXP-018: Controversy scores from jury disagreement

**Status:** Ready to run
**Effort:** Small
**Priority:** Medium
**Agent:** awards-builder

---

## Task

Compute a controversy/uncertainty score for each project in the v6 shortlist based on how much the six juries disagreed about it, and add these scores to the results output.

## Inputs

- `iterations/v6/jury-delegations/` — all six jury ranked shortlists and winner selections
- `results.json` — current rankings

## Method

For each project that appeared in at least one jury's shortlist:

1. Count how many of the six juries included it in their shortlist: `jury_presence` (0–6)
2. For projects in multiple juries, compute rank variance across juries
3. Classify each project:
   - **Consensus** (present in 5–6 juries, rank variance ≤ 3): stable assessment
   - **Contested** (present in 3–4 juries, or rank variance > 5): moderate disagreement
   - **Divisive** (present in 1–2 juries, one jury ranks it very high): strong disagreement
   - **Invisible** (present in 0 juries): suppressed by all

4. For projects that were each jury's winner pick, note the `winner_count` (how many juries picked this project as their winner — max 1 per jury, total max 6)

5. Add `controversy_label`, `jury_presence`, and `rank_variance` fields to results.json

## Output

- `results-with-controversy.json` — enriched results file with controversy metadata
- `experiments/EXP-018/controversy-analysis.md` — summary statistics and interesting findings (most divisive project, most invisible highly-ranked project, etc.)

## Constraints

- Do NOT overwrite `results.json`
- Work only from existing jury outputs — no new model runs

## Definition of done

Controversy metadata added to results, analysis note written.
