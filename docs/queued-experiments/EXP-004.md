# EXP-004: Enrichment schema citation validation at generation time

**Status:** Ready to run
**Effort:** Small
**Priority:** High
**Agent:** awards-builder

---

## Task

Add a validation step to the enrichment pipeline that rejects descriptive citation strings without a URL or DOI before they are written to dossiers, preventing the recurrence of the 538-citation cleanup.

## Inputs

- Enrichment pipeline scripts (locate in `scripts/` directory)
- `data/enriched/` — canonical dossier files (for reference schema)
- `reports/2026-03-20-citation-verification.md` — defines the citation categories that should be rejected

## Method

1. Locate the enrichment script(s) that generate `news_articles` and `academic_citations` fields
2. Add a validation function that rejects any citation entry that:
   - Is a bare string without a URL or DOI key
   - Matches patterns like "Coverage in...", "Referenced in...", "Citations in academic literature on..."
   - Is a dict/object without a `url` or `doi` field
3. Add the validation as a post-generation filter: any entry that fails validation is dropped before writing
4. Test on 10 sample dossiers — verify that clean citations pass and vague strings are rejected
5. Document the validation rules added

## Output

- Modified enrichment script with validation added
- `experiments/EXP-004/test-results.md` — test run on 10 dossiers, showing before/after citation counts

## Constraints

- Do NOT re-run enrichment on all 321 dossiers as part of this experiment
- Do NOT modify canonical dossier files during this experiment
- Preserve backwards compatibility — clean structured citations (URL/DOI objects) must still pass

## Definition of done

Validation function added to enrichment pipeline, test results documented.
