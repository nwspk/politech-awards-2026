# EXP-001: Alternative jury promotion rules

**Status:** Ready to run
**Effort:** Small
**Priority:** High
**Agent:** awards-builder

---

## Task

Take the six v6 jury verdicts and apply three alternative promotion rules to determine whether confidence-ranked promotion (which always selects Grok) is the best approach.

## Inputs

- `iterations/v6/jury-delegations/` — all six jury deliberation outputs (winners, confidence scores, ranked shortlists)
- `results.json` — current state (Grok-promoted AlgorithmWatch, score 97)

## Method

Apply three promotion rules to the existing six jury outputs:

1. **Borda count**: For each jury's ranked shortlist, assign points (n = highest, 1 = lowest). Sum across all six juries. Winner = highest total.
2. **Weighted by jury diversity**: Weight each jury's vote by how different its winner is from the median winner. Juries that agree with the majority get lower weight; juries with divergent winners get higher weight.
3. **Median position**: For each project, find its median rank across all six juries' shortlists. Winner = lowest median rank.

## Output

- A comparison table: current winner (AlgorithmWatch) vs each alternative rule's winner
- New `results.json` for each rule (save as `results-borda.json`, `results-weighted.json`, `results-median.json`)
- A brief analysis note: do the alternative rules change the winner? Which projects move most?

## Constraints

- Do NOT run new pipeline executions — work only from existing jury outputs
- Do NOT overwrite the canonical `results.json`
- Output analysis to `iterations/project-b/` or a new `experiments/EXP-001/` folder

## Definition of done

Analysis note written, three alternative results files produced, findings documented.
