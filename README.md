# Political Technology Awards 2026

Public, inspectable ranking process for 321 civic and political technology projects.

## Start here

- [CONTRIBUTING.md](CONTRIBUTING.md) - fastest path to ship a contribution
- [docs/operating/process.md](docs/operating/process.md) - committee workflow and voting rules
- [docs/operating/technical.md](docs/operating/technical.md) - bot triggers, generated files, and script reference
- [scripts/README.md](scripts/README.md) - script map and common commands

## Quick start

```bash
npm install
npx tsx the-algorithm.ts
```
