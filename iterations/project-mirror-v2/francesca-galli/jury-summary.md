## Model behaviour notes

**GPT-4.1:** Consistent progressive anchor bias — privacy/security and civil liberties tools score 150–260 ranks higher than Francesca's constitution assigns. UK civic data infrastructure and local-government tools score 150–210 ranks lower. Decidim is the top jury pick (median 93) with high instability (range 34), suggesting GPT-4.1 applies Francesca's criteria to it differently across runs. LittleSis (median 91, range 0 across runs 2–3) is the most robustly high-scoring project. Run 1 anomaly (120 nulls) likely reflects an API batch handling issue — not an indication of those projects' fit.
