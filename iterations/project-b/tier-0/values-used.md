## Ideological Profile of This Ranking

The implicit values reveal a consistent profile:
- **Progressive-technocratic**: Prefers civil society advocacy + evidence-based tools
- **Anti-corruption weighted**: Punishes opaque systems, rewards accountability
- **Western-leaning**: International = primarily EU/UK/US; "Global South" is a modifier not a primary lens
- **Efficiency-hostile**: Pure government service delivery tools (GOV.UK stack) undervalued
- **Scale bias**: Rewards reach; punishes depth without scale
- **Open source ideological alignment**: Treats openness as a civic virtue, not just technical property

This profile is consistent with what the literature on LLM political bias predicts: left-of-centre, civil-society-oriented, accountability-focused, with implicit Western/English-language framing as default.
