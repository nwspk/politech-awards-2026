## Key Differentiating Values

The values that most differentiate framings (highest variance across framings):
1. **Government adoption** — beloved by technocratic/conservative, toxic to libertarian
2. **Worker rights** — uniquely progressive
3. **Decentralisation** — uniquely libertarian
4. **Low-resource deployment** — uniquely global south
5. **Institutional stability** — uniquely conservative

## Projects That Are "Ideology-Free Infrastructure"

vTaiwan, Decidim, ODK, CKAN, and mySociety rank across all framings because they embed civic values architecturally without political identity. They are the "infrastructure layer" that all ideological framings can use for different purposes.
