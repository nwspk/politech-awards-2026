# Tier 1 — Values Stability Analysis

Same implicit values as Tier 0 were operative across all three runs. This file documents which values were *stable* and which were *variable* across runs.

## Stable Values (Consistent across all 3 runs)

- **Policy impact legibility**: All three runs rewarded documented outcomes consistently
- **Accountability / watchdog orientation**: Anti-corruption and algorithmic accountability projects always ranked high
- **Decade-plus longevity**: Long-standing projects maintained advantage in all runs

## Variable Values (Shifted between runs)

- **Worker rights emphasis**: Activated strongly in Run B, absent in Run C
- **Digital privacy / surveillance resistance**: Activated in Run C's issue-area scan, lower in standard scan
- **Institutional legitimacy vs grassroots**: Run B rewarded CONSUL's grassroots deployments higher; Run A penalised its institutional feel
- **Underdog equity**: Only activated when explicitly attending to underdog signals (Run B)

## Interpretation

The stable values form a "core" ideological kernel that remains constant. The variable values represent a "periphery" that shifts based on what aspects of projects happen to be salient during evaluation.

This matches the AAAI/ACM 2024 research finding: LLM value alignment is consistent at the core but sensitive to prompt framing at the margins.
