# Tier 5 — Values Used (Pairwise Comparison)

## Values Active in Pairwise Mode

Pairwise comparison activates a different set of decision heuristics compared to global ranking:

### Primary decision heuristics (from 5-word reason analysis):

1. **Outcome volume** — "higher outcomes documented" (most common reason, 11/50 comparisons)
2. **Evidence strength** — "stronger evidence" (7/50) — directly_cited beats correlated beats anecdotal
3. **Open source** — "fully open source" (5/50) — consistent tiebreaker
4. **Scope/scale** — "broader/international scope" (4/50)
5. **Specificity of impact** — quantified outcomes win ("saves 6-10%") over qualitative descriptions

## Values NOT Active in Pairwise Mode

Compared to Tier 0 implicit values:

| Tier 0 Value | Active in Tier 5? | Why not? |
|---|---|---|
| Accountability/watchdog orientation | Partly | Less prominent when specific outcomes compared |
| Underdog equity | No | Comparison frame doesn't trigger compassion heuristic |
| Narrative appeal | No | Side-by-side comparison strips narrative |
| Prestige/reputation | Partly | Overridden by specific comparison advantages |

## The Pairwise Compression Effect

Pairwise comparison compresses multi-dimensional quality into a single binary choice. This creates a "compression artefact":

Projects with **unidimensional excellence** (best FOI platform, most quantified savings) beat projects with **multidimensional excellence** (good across many dimensions but not necessarily best in any single one).

This explains why:
- Aleph (OCCRP) collapses from #5 to #23 — it's excellent in many ways but loses specific comparisons
- OpenProcurement rises from #22 to #5 — it has the single most defensible comparison claim (ProZorro savings)
- Open Contracting Partnership falls from #3 to #24 — similar story to Aleph

## Implication for Award Design

If pairwise voting is used in the actual awards process, the winner will be the project with the most defensible single comparative advantage, not necessarily the most important project overall. This is a known limitation of tournament-style selection mechanisms.
